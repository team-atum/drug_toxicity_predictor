About

About the Project

Built with cutting-edge ML techniques for accurate drug toxicity assessment

XGBoost Model

Gradient-boosted decision tree ensemble trained with optimized hyperparameters and class imbalance handling via scale_pos_weight for robust toxicity classification.

Tox21 Dataset

NIH Tox21 challenge dataset containing ~8,000 compounds tested across 12 biological assays covering nuclear receptor and stress response pathways.

Molecular Features

2048-bit Morgan circular fingerprints (ECFP4) combined with 7 physicochemical descriptors computed via RDKit for comprehensive molecular representation.

Flask API

RESTful backend serving real-time predictions with RDKit molecular parsing, descriptor computation, and multi-assay inference in a single API call.
